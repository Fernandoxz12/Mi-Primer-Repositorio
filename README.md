# Mi-Primer-Repositorio
# Mi Repositorio de Datos 

Este repositorio contiene dos archivos principales en formato **CSV**, utilizados para organizar información de **ventas** y **clientes**. Su propósito es practicar la gestión de datos y el uso de GitHub para almacenar y estructurar información.

## Contenido del Repositorio

### 1. datos_ventas.csv
Este archivo almacena el registro de ventas realizadas en distintas fechas y sucursales.

**Columnas incluidas:**
- Fecha  
- ID_Venta  
- Producto  
- Categoría  
- Cantidad  
- Precio_Unitario  
- Total_Venta  
- Vendedor  
- Sucursal  

**¿Para qué sirve?**  
Permite analizar ventas por categoría, vendedores, fechas y sucursales, además de calcular ingresos totales.

---

### 2. datos_clientes.csv
Archivo que contiene la información básica de los clientes registrados.

**Columnas incluidas:**
- ID_Cliente  
- Nombre  
- Apellido  
- Correo electrónico  
- Teléfono  
- Ciudad  
- Fecha_Registro  

**¿Para qué sirve?**  
Permite identificar clientes, organizarlos por ubicación y realizar análisis de seguimiento o segmentación.

---

## Objetivo del Proyecto
- Practicar la organización de datos en formato CSV.  
- Mantener una estructura clara dentro del repositorio.  
- Facilitar futuras actividades de análisis, reportes y visualización.  
- Aplicar buenas prácticas de manejo de archivos en GitHub.

---

## Notas
- Los datos son de práctica y pueden ampliarse o modificarse.  
- Se recomienda mantener consistencia en los formatos y nombres de columnas.  
- Este repositorio puede servir como base para ejercicios más avanzados de análisis de datos.
